# Unreal Engine keybindings

15 keyboard shortcuts.

| Keys | Action | Description | Status |
| --- | --- | --- | --- |
| `⌃ Space` | Content Browser | Open or focus the Content Browser. | VERIFIED |
| `F1` | Context documentation | Open documentation for the current editor context. | VERIFIED |
| `⌃ W` | Duplicate actor | Duplicate selected actors. | VERIFIED |
| `F` | Focus selection | Frame selected actors in the viewport. | VERIFIED |
| `G` | Toggle game view | Hide or show editor-only viewport icons. | VERIFIED |
| `⌃ N` | New level | Create a new level. | VERIFIED |
| `⌃ O` | Open level | Open an existing level. | VERIFIED |
| `⌥ P` | Play in editor | Start Play In Editor. | VERIFIED |
| `E` | Rotate tool | Activate rotation controls. | VERIFIED |
| `⌃ S` | Save current level | Save the active level. | VERIFIED |
| `⌃ ⇧ S` | Save all | Save all modified assets and levels. | VERIFIED |
| `R` | Scale tool | Activate scale controls. | VERIFIED |
| `⌃ ⇧ P` | Search commands | Open action search. | COMMON |
| `Esc` | Stop play session | Stop the active Play In Editor session. | VERIFIED |
| `W` | Translate tool | Activate translation controls. | VERIFIED |
