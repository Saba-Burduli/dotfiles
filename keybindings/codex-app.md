| `Esc` | Interrupt task | Stop the active task. | VERIFIED |

| `⇧ Enter` | Insert newline | Insert a line without submitting. | VERIFIED |
| `⌘ O` | Open project | Open a local workspace. | VERIFIED |

| `Enter` | Submit prompt | Send the current prompt. | VERIFIED |
