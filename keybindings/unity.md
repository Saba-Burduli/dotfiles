# Unity keybindings

15 keyboard shortcuts.

| Keys | Action | Description | Status |
| --- | --- | --- | --- |
| `⌘ ⇧ B` | Build | Open or run the build workflow. | VERIFIED |
| `⌘ B` | Build and run | Build the project and run it. | VERIFIED |
| `⌘ ⇧ C` | Open Console | Open the Console window. | VERIFIED |
| `⌘ D` | Duplicate | Duplicate the selection. | VERIFIED |
| `F` | Frame selection | Center the Scene view on the selection. | VERIFIED |
| `W` | Move tool | Activate the move tool. | VERIFIED |
| `Q` | Pan tool | Activate the hand/pan tool. | VERIFIED |
| `⌘ ⇧ P` | Pause | Pause Play mode. | VERIFIED |
| `⌘ P` | Play | Enter or exit Play mode. | VERIFIED |
| `⌘ 5` | Open Project window | Focus the Project window. | VERIFIED |
| `E` | Rotate tool | Activate the rotate tool. | VERIFIED |
| `⌘ S` | Save scene | Save the active scene. | VERIFIED |
| `R` | Scale tool | Activate the scale tool. | VERIFIED |
| `⌘ ⌥ P` | Step frame | Advance one frame while paused. | VERIFIED |
| `V` | Vertex snap | Hold while moving to snap vertices. | VERIFIED |
